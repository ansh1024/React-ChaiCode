# ⚛️ React Fundamentals

> Building my React foundation — one component at a time.

This repository marks the beginning of my journey into **React.js**, starting with the fundamentals of component-based development and gradually moving toward building real-world applications.

## 🚀 What's Inside?

This project explores the core ideas behind React, including:

* ⚛️ React components
* 🧩 JSX
* 🔗 Importing & exporting components
* ♻️ Reusable UI components
* 🏗️ Component composition
* 📦 React Fragments
* ⚡ React development with Vite

The goal isn't just to follow tutorials — it's to understand **how React actually works** and build a strong foundation for more advanced projects.

## ▶️ Getting Started

### 1. Clone the repository

```bash
git clone <repository-url>
cd <repository-folder>
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

Then open:

**http://localhost:5173/**
